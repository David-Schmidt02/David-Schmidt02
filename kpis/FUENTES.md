# Tipografías

Las tarjetas embeben dos tipografías de Google Fonts, ambas con licencia [SIL Open Font License 1.1](https://openfontlicense.org), que permite incluirlas en otros trabajos:

- **Pixelify Sans** (`pixelify-sans.woff2`), de Stefie Justprince: títulos y nombre.
- **VT323** (`vt323.woff2`), de Peter Hull: números y textos chicos.

Van embebidas porque GitHub no carga fuentes externas dentro de las imágenes SVG.
